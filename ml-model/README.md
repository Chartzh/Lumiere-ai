# 🧠 Lumiere - Machine Learning Model

Bagian ini berisi seluruh kode sumber, eksperimen notebook, dan arsitektur model Deep Learning untuk proyek Lumiere.

## 🛠️ Tech Stack & Library
* Framework Utama: TensorFlow & Keras
* Pemrosesan Data: Pandas & NumPy
* Dataset: MovieLens 1M Baseline

## 📁 Struktur Folder
* `/data`: Penyimpanan lokal untuk sampel dataset (tidak di-push ke GitHub).
* `/notebooks`: File Jupyter Notebook (.ipynb) hasil eksplorasi dari Kaggle/Colab.
* `/src`: Skrip Python (.py) produksi untuk arsitektur model, preprocessing, dan pelatihan.
